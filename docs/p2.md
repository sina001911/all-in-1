# P2 — Browser Engine, Screenshot Engine, Artifact Storage

## What P2 adds

The perception foundation: the system can now launch a real browser, navigate
to a **localhost-only** target, capture a screenshot, and store it as a
content-addressed artifact with provenance metadata.

```
ScreenshotEngine ──▶ BrowserEngine (Playwright) ──▶ ArtifactStore
                          │                              │
                  assertHostAllowed()            SHA-256 content addressing
                          │                       + metadata sidecar
                 localhost-only gate              + retention sweep
```

## Modules

| Module | Owns |
|---|---|
| `src/errors.ts` | Typed failure model: `AllInOneError` with `code` (discriminant) + `category` + `retryable`; `Result<T>` union; `toAllInOneError()` narrowing |
| `src/browser/types.ts` | `BrowserEngine` contract, `ScreenshotRequest`, `OpenedPage`, viewport/navigation options |
| `src/browser/playwright-adapter.ts` | The only component allowed to launch a browser; lazy `import("playwright")`; enforces host policy before every `goto` |
| `src/browser/fake-engine.ts` | Deterministic in-memory engine for tests; enforces the same host policy |
| `src/screenshot/engine.ts` | Navigate → capture → store, with per-job error isolation in `captureAll()` |
| `src/artifacts/store.ts` | Content-addressed storage, metadata sidecars, size ceiling, retention sweep |

## Security boundaries (verified by tests)

1. **Host policy is enforced inside the engine**, not by callers. `open()`
   calls `assertHostAllowed()` *before* any navigation, so no caller can bypass
   the localhost-only boundary. Non-loopback targets are rejected without ever
   launching a browser (verified on the real engine).
2. **Artifact ids are strictly validated** (`kind/<64-hex>.<ext>`). Traversal
   attempts (`../../etc/passwd`, encoded variants) raise
   `PATH_TRAVERSAL_BLOCKED` under category `security`.
3. **Writes are confined to the store base** — a second defence behind id
   validation, checked via `relative()` + `isAbsolute()`.
4. **Playwright is lazily resolved.** The package declares no runtime
   dependency; a production install without Playwright degrades to a typed
   `BROWSER_UNAVAILABLE` error rather than a module-resolution crash.
5. No credentials, no extensions, no downloads, no network beyond localhost.

## Typed failure model

Every failure carries a machine-readable code and a stable category:

| Category | Codes |
|---|---|
| `security` | `HOST_BLOCKED`, `PATH_TRAVERSAL_BLOCKED`, `MODE_VIOLATION` |
| `browser` | `BROWSER_LAUNCH_FAILED`, `NAVIGATION_FAILED`, `NAVIGATION_TIMEOUT`, `SCREENSHOT_FAILED`, `PAGE_CLOSED` |
| `artifact` | `ARTIFACT_WRITE_FAILED`, `ARTIFACT_READ_FAILED`, `ARTIFACT_NOT_FOUND`, `ARTIFACT_TOO_LARGE`, `RETENTION_ENFORCEMENT_FAILED` |
| `unavailable` | `BROWSER_UNAVAILABLE` |
| `config` | `INVALID_CONFIG`, `INVALID_ENV_REF` |

`retryable` distinguishes transient failures (navigation, writes) from
permanent ones (missing Playwright, blocked hosts).

## CLI

```sh
node src/cli.ts shot http://127.0.0.1:<port>/   # capture + store
```

Writes to `~/.all-in-1/artifacts/screenshot/<sha256>.png` with a
`<sha256>.png.json` provenance sidecar.

## Verification

- `npx tsc --noEmit` — clean (strict).
- `npx vitest run` — 14 files, 90 tests, all green.
- Acceptance test: a **real** Chromium capture of a localhost fixture server,
  verified PNG signature + SHA-256 match against stored metadata. Skips
  gracefully (with a warning) when no browser binary is available.
- P1/P1.1 CLI smoke tests unchanged: `detect`, `policy`,
  `resolve MAIN_CODER` (still throws `RoleNotRoutableError`, exit 1).
- Host policy: `shot https://example.com/` is rejected before launch.

## Frozen defaults

All P0/P1/P1.1 frozen contracts are unchanged: MAIN_CODER immutability,
`spendBudgetUsd = 0`, `FREE_ONLY`, media disabled, zero **runtime**
dependencies (Playwright is dev-only), no `opencode.jsonc` change.
